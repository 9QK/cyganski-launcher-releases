# Cyganski Launcher — downloads

A free launcher for **Assetto Corsa** and **Assetto Corsa EVO**: install mods, tracks and skins, set up graphics (CSP, Pure), Quick Drive and online servers, all in one place.

## Download

Get the latest `Cyganski Launcher_x.y.z_x64-setup.exe` from **[Releases](../../releases/latest)** and run it. It installs for your Windows user only, no admin rights needed.

### “Windows protected your PC”

The installer isn't signed with a paid certificate yet, so Windows SmartScreen may warn you the first time. Click **More info → Run anyway**. Updates inside the launcher don't show this warning.

## Updates

The launcher checks for a new version once per start and offers it itself. Every update is signed, and the launcher refuses anything that isn't.

## Requirements

- Windows 10 or 11 (64-bit)
- Assetto Corsa and/or Assetto Corsa EVO from Steam
